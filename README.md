# JS HiFi Player v11

Android HiFi music player.

## Recursos planejados

- Media3 / ExoPlayer
- Auto Gain inteligente
- Proteção contra clipping
- Equalizador estéreo
- VU Meter LED
- VU Meter analógico
- Spectrum Analyzer
- Navegador de arquivos
- Navegação entre pastas e músicas
- Busca de músicas
- Fila de reprodução
- Shuffle
- Repeat
- Playlists
- Adicionar músicas às playlists
- Adicionar pastas às playlists
- Retomar última reprodução

## Compatibilidade

- Android 7.0+
- Minimum SDK 24
- Target SDK 34
